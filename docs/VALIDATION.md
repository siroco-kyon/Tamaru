## 配布EXEとブラウザー

Windows x64 EXEを作成し、Pythonの別プロセスではなく、このEXEから起動したWebアプリで以下を操作しました。

- 初期管理者のログイン。
- Webから2人目の管理者を追加し、そのIDでログイン。
- 「今すぐ収集」の実行と結果反映。
- フォルダの配下を含む集計と、明細への絞り込み。
- CSVのダウンロード。
- 収集時刻の変更。
- 操作履歴の表示とログアウト。

動作確認にはサンプルのファイルとアカウントだけを使用しています。GitHubや配布ZIPにそのデータ・アカウントは含めません。

## 依存関係

実行時依存関係を`requirements.txt`に固定しました。`pip-audit`による確認時点で、既知の脆弱性は検出されませんでした。

## 未検証の範囲

- 設置先のWindowsサーバー、社内証明書、実際の共有・資格情報を使った結合テスト。
- サーバー再起動・ログオフ状態での常駐起動とネットワーク認証。
- 100人分の実ファイルと、同時アクセスを使った負荷試験。
- LinuxはGitHub Actionsのテスト対象です。Windows共有の実環境確認の代わりにはなりません。

これらは設置先で確認する必要があります。ファイル名・パスの管理データはサーバー内のローカルディスクに保存します。

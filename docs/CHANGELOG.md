# 変更履歴

## 0.1.1 — 2026-10-28

- 将来用に削除候補作成・退避・退避後の完全削除の内部処理を追加。
- 削除機能は常時無効。実行API・CLI・定期実行への接続や、画面の実行ボタンは追加しない。
- 設定・環境変数からの有効化も提供しない。通常運用は調査専用のまま。
- 同じ場所への別ファイルの配置に備えるファイルID照合、Windowsハンドルによる操作、期間・鮮度・上限・台帳・排他の検証を追加。
- 無効化と内部処理を検証するテストを追加。実際の共有に対する削除テストは未実施。

## 0.1.0 — 2026-10-28

- 社内LAN向けのWeb閲覧、複数管理者、日次・手動収集、階層集計、CSV、FolderAgeからの移行を追加。

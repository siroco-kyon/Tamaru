# Tamaru（たまる）

受け渡し用の共有フォルダにあるファイルを、**場所・容量・初回検出からの滞留日数**で確認する、社内LAN向けのWebアプリです。

Python / FastAPI / Uvicorn / SQLiteで構成します。Watashiとは別のアプリとして動作します。調査対象のファイルを削除・移動・編集せず、中身も読みません。

## 主な機能

- 管理者ID・パスワードによるログイン。初期管理者はサーバーのコンソールで登録します。
- Web画面から管理者を追加、有効化・無効化、パスワードの再設定。全管理者は同じ権限です。
- 1日1回の自動収集（標準は日本時間02:00。画面で変更・無効化可能）。
- Web画面の「今すぐ収集」で手動実行。自動・手動の重複実行は防止します。
- 収集中も前回の一覧を閲覧でき、収集完了後に結果をまとめて反映します。
- ファイルごとの所在・容量・滞留日数・初回検出日時・最終確認日時・確認状態。
- 各フォルダ直下の集計、または指定階層（部署・個人など）の配下を含む集計。
- パス検索・日数フィルター・並べ替え・100件ずつのページ表示・CSV出力。
- 収集履歴・エラー・管理者の操作履歴。
- FolderAgeから初回検出日時を引き継ぐ取り込みコマンド。

## 削除機能の準備状況（v0.1.1）

将来用に、候補作成・退避・7日間の猶予後の完全削除の内部処理を実装しています。**このバージョンでは実行できません。画面に削除ボタンはなく、実行API・コマンド・定期処理の接続もありません。設定や環境変数による有効化もできません。** 通常運用は引き続き調査専用です。

内部処理は隔離したテストファイルだけで検証しています。有効化には将来のコード変更と、退避先・権限・共有上の動作の確認が必要です。詳細は [docs/RETENTION.md](docs/RETENTION.md) を参照してください。

## 動作の考え方

既にあるファイルも、新しく増えたファイルも、初めて検出した時刻から0日で記録します。元ファイルの更新日時は起点にしません。

識別は「対象フォルダ＋フルパス」です。同じ場所への編集・上書き・同名ファイルへの置き換えは日数を継続し、名前変更・別の場所への移動は新しい記録です。正常な収集で消失を確認してから同じ場所へ再出現したファイルは0日からです。収集間の削除・再配置は検出できません。

日数は24時間ごとに加算します。ファイルの実在は最終確認時点の情報です。容量はファイルの論理サイズであり、ディスクの占有量・空き容量ではありません。

## Windowsで試す

Python 3.11以上を使用します。まずローカルで確認し、LAN公開にはHTTPSを設定してください。

```powershell
git clone https://github.com/siroco-kyon/Tamaru.git
cd Tamaru
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .

# 初期管理者。パスワードは画面に表示せず、対話入力します。
.\.venv\Scripts\python.exe -m tamaru --state C:\TamaruData create-admin admin --display-name 管理者

# このPCだけで試すHTTPモード
.\.venv\Scripts\python.exe -m tamaru --state C:\TamaruData serve --dev-http
```

`http://127.0.0.1:8765/`を開き、登録したIDでログインします。対象フォルダを保存して「今すぐ収集」を押すと記録が始まります。既定のユーザー・パスワードはありません。

Windows用の配布EXEを使用する場合は、上記の`python -m tamaru`を`Tamaru.exe`に置き換えられます。Pythonのインストールは不要です。**EXEをダブルクリックするだけではサーバーは起動しません。最初に管理者登録と起動引数の設定が必要です。**

## 社内LANへ公開する

設置方法・HTTPS・自動起動は [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) を参照してください。

基本構成は、1台のWindowsサーバー上でTamaruを1プロセス起動し、同じサーバーのローカルディスクへDBを保存する形です。収集対象はUNCパスで指定します。

```mermaid
flowchart LR
    Share[受け渡し共有フォルダ] -->|属性・サイズ・日時を取得| Collector[日次 / 手動の収集]
    Collector --> Stage[収集用DB]
    Stage -->|終了時に反映| DB[管理DB]
    DB --> API[FastAPI / Uvicorn]
    API -->|HTTPS・管理者ログイン| Browser[社内PCのブラウザー]
```

Web画面を閉じても、サーバープロセスが起動していれば自動収集します。**プロセスが停止している間は収集しません。** サーバー起動時の常駐設定が必要です。

## 管理者について

管理者は全対象フォルダの一覧・CSV・エラー・操作履歴を閲覧でき、収集や設定変更、他の管理者の追加・変更もできます。閲覧専用や部署別の権限は、このバージョンにはありません。

最後の有効な管理者は無効化できません。パスワード再設定・有効状態の変更により、その管理者の既存ログインは解除されます。無効化は元に戻せます。管理者の削除機能はありません。

パスワードを忘れた場合は、サーバーにログオンして次を実行します。新しいパスワードを対話入力し、対象アカウントを有効に戻します。

```powershell
python -m tamaru --state C:\TamaruData reset-password admin
```

## 収集とエラー

- シンボリックリンク、ジャンクション、その他の再解析ポイントをたどりません。
- 対象の親子重複と、ツール・管理データが調査範囲に入る設定を拒否します。
- 共有への接続不可や権限エラーは記録します。その対象で読み取りエラーが出た回は、見つからなかった既存ファイルを一括で消失扱いにしません。
- 未確認の記録は、前回の容量・日時を残して表示します。画面に表示するエラーは対象ごとの最新収集から最大100件です。
- 空フォルダは集計に出ません。隠しファイルも通常ファイルとして集計します。
- 日次収集は指定したタイムゾーンの日付ごとに1回です。指定時刻を過ぎて起動した日は、未実行なら次の確認周期（約30秒以内）で収集します。過去の日数分を繰り返して実行することはありません。
- 収集中の日次実行要求は待ち合わせ、重複して動きません。手動収集は1日に何度でも行えます。
- 日次収集が失敗した回の自動再試行は翌日です。必要に応じてWebから手動収集してください。中断された日次処理は再起動後に再受付します。
- 収集の停止・中断機能はありません。終了時は処理完了を待ちます。共有サーバーの応答に時間がかかる場合、終了も待機します。

## 管理データ・バックアップ

管理データには社内ファイル名とパスが含まれます。サーバー側のアクセス権で保護してください。

```text
C:\TamaruData\
  app.sqlite3          管理者・ログイン・設定・操作履歴
  inventory.sqlite3    ファイル観測記録・収集履歴
  settings.json        対象フォルダ
  staging\             収集中の一時DB（同程度の容量を使います）
  *.lock               重複起動防止。残っていても正常です
```

DBに加え、収集中の一時DBとSQLiteのジャーナルの空き容量を確保してください。管理データは共有ドライブへ置けません。DBを各PCから直接開く構成にも対応しません。

バックアップはTamaruを停止し、収集が終了した状態で、管理データフォルダ全体をコピーします。復元も停止中に行います。**初回検出日時を保持するため、更新時も同じ管理データを引き継いでください。**

消失したファイルの記録・収集履歴・操作履歴は保持するため、DBは長期運用で増えます。セッションは期限切れのものを起動時・ログイン時に整理します。

## FolderAgeからの移行

FolderAgeを停止し、バックアップを取ってから、Tamaruのまだ観測記録がない保存先へ取り込みます。管理者登録の前後どちらでも実行できます。

```powershell
python -m tamaru --state C:\TamaruData import-folderage C:\Tools\FolderAge\data
```

ファイルの初回検出日時と観測履歴、対象フォルダ設定を引き継ぎます。既に観測記録がある保存先への上書きは拒否します。取り込み元のファイル内容は変更しません（排他用lockファイルは利用します）。

## セキュリティ上の実装

- Argon2idによるパスワードハッシュ。平文パスワードは保存しません。
- 推測困難なサーバー側セッション。DBにはセッショントークンのハッシュを保存します。
- ログインは8時間で期限切れ。CookieはHttpOnly・SameSite=Strict、通常運用ではSecure付きです。
- ログインと状態変更APIはCSRF対策付き。管理者の変更・収集・設定変更は認証とCSRF検証の両方が必要です。
- ログイン失敗はIP・IDごとに15分で10回を超えると一時制限します。
- 通常運用ではHTTPS必須。HTTPでの試運転は明示的な`--dev-http`とループバック接続に限定します。
- LANのプライベートアドレス・ループバック・リンクローカル・IPv6 ULA以外からの接続を拒否します。ファイアウォールでも公開範囲を限定してください。
- ホスト名の許可リスト、CSP、フレーム埋め込み防止、本文サイズ上限、CSVの式エスケープを設定します。
- セッション・認証データ・実ファイルの観測記録・証明書・秘密鍵はGit管理しません。

## 開発・確認

```powershell
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
python -m pip install pytest httpx
python -m pytest -q
```

アカウント・セッション・権限・CSRF・最終管理者保護・日次実行・手動実行・重複防止・結果の一括反映・再走査・エラー・リンク除外・階層集計・CSV・移行をテストします。GitHub ActionsでもWindows/Linuxで実行します。

共有サーバー・社内証明書・社内アカウントを使った実環境の結合テストは、設置先で必要です。ローカルテストの結果を共有先の処理速度の保証としては扱いません。

Windows EXEのビルド:

```powershell
python -m pip install pyinstaller
python -m PyInstaller --clean --noconfirm --onefile --name Tamaru --add-data "tamaru/static;tamaru/static" --collect-data tzdata --hidden-import uvicorn.logging --hidden-import uvicorn.loops.asyncio --hidden-import uvicorn.protocols.http.h11_impl --hidden-import uvicorn.lifespan.on launcher.py
```

`dist\Tamaru.exe`を生成します。ビルド環境と同じOS・CPUアーキテクチャ向けです。
